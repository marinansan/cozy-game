# Cozy Game

Juego cozy de una librería-cafetería mágica en un barrio japonés que recupera su alma.

## Documentación

- `gat/narrative/story.md`: historia principal, tema, estructura y misterio
- `gat/narrative/world.md`: el barrio, la niebla, las zonas y las pistas de arte
- `gat/narrative/characters.md`: personajes
- `gat/narrative/quests.md`: estaciones, ritual con los espíritus y ciclo del día
- `gat/narrative/dialogue.md`: estilo de diálogo y voz

## Tecnología

Phaser (juego web en JavaScript). Plataforma inicial: navegador y PC.
